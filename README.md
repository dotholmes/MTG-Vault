# MTG Vault
MTG Vault is a full-stack web application for Magic: The Gathering players. The application allows users to search for cards, view detailed card information, build decks, save favorites, and manage personal collections.

This project is being built as a portfolio piece to demonstrate modern full-stack web development using the MERN stack and third-party API integration.

## Features
### Current Features
- Search Magic: The Gathering cards using the Scryfall API
- View detailed card information
- Responsive user interface
### Planned Features
- User authentication
- Favorite cards
- Deck builder
- Collection tracker
- Deck statistics and analytics
- Collection valuation
- Dark mode support
